# عِزّ المسابقات

تطبيق Flutter أولي لعرض مسابقات **مزاين الإبل** و**سباقات الهجن** بواجهة عربية واتجاه RTL، مع بيانات تجريبية محلية.

## المتطلبات

- Flutter SDK (إصدار حديث متوافق مع Dart 3.3+)
- جهاز أو محاكي للتشغيل

## التشغيل

```bash
flutter pub get
flutter run
```

## المميزات الحالية

- واجهة Material 3 عربية بالكامل
- اتجاه من اليمين إلى اليسار على مستوى التطبيق
- شاشة رئيسية تحتوي بانر ترحيبي وقسم وصول سريع وقائمة مسابقات قادمة
- شريط تنقل سفلي: الرئيسية، المسابقات، النتائج، حسابي
