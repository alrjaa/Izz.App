# عِزّ المسابقات

تطبيق Flutter عربي RTL لمنظومة **مزاين الإبل** و**سباقات الهجن** مع هيكل منتج قابل للتوسع، وبيانات تجريبية محلية بدون أي مفاتيح API.

## ما الذي تم تنفيذه الآن

- بنية Flutter منظّمة (app / features / domain / data)
- Design System صحراوي (رملي/بني/ذهبي) مع Material 3
- تعريب كامل واتجاه RTL على مستوى التطبيق
- تدفق Onboarding + OTP تجريبي محلي
  - إدخال رقم الجوال
  - التحقق برمز تجريبي `1234`
  - اختيار نوع الحساب
  - اختيار الاهتمامات
- واجهات أساسية جاهزة للتطوير:
  - الرئيسية (تبويب مزاين/هجن + بث حي + مسابقات + وسائط + رعاة)
  - قسم المزاين
  - قسم سباقات الهجن
  - مركز الوسائط
  - صفحة حساب/مالك + بطاقة ذلول
  - لوحة إدارة (تظهر عند دور admin)
- مخطط قاعدة بيانات Supabase/PostgreSQL كامل داخل:
  - `supabase/migrations/20260917_000001_initial_schema.sql`
  - يشمل الجداول المطلوبة، Enums، وتفعيل RLS مع سياسات أولية حسب الدور.

## التشغيل

```bash
flutter pub get
flutter run
```

للويب:

```bash
flutter run -d chrome
```

## ملاحظات مهمة

- المصادقة الحالية OTP **محلية تجريبية** وغير مرتبطة بخدمة خارجية.
- البيانات الحالية Mock Data داخل التطبيق لتسريع التطوير.
- الخطوة التالية: ربط الشاشات فعليًا بـ Supabase API/Realtime/Storage.
